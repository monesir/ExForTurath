# إضافة تحسين وتجميل موقع تراث (Turath Redesign Extension)

إضافة مخصصة لمتصفح جوجل كروم (Chrome Extension) تهدف إلى إعادة تصميم الواجهة الأمامية لموقع **[تراث](https://app.turath.io/)** ليصبح أكثر جمالاً وأناقة وراحة للعين، مع الحفاظ على روح التراث الإسلامي عبر ألوان دافئة وزخارف أصيلة.

## ✨ المميزات (Features)

*   **ثيم داكن تراثي:** تحويل ألوان الموقع بالكامل إلى خلفيات شفافة تبرز خلفها زخرفة إسلامية خفيفة، مع إضاءة النصوص والأيقونات بلون ذهبي/نحاسي أنيق (`#B59954`).
*   **راحة بصرية فائقة (Glassmorphism):** إضافة تأثير التغبيش الزجاجي (Blur) خلف صفحات الكتب لتسهيل القراءة ولإبراز النص بوضوح وراحة تامة.
*   **أشرطة تمرير مخصصة:** تصميم جديد وراقي لشريط تمرير الصفحات الجانبي وشريط التنقل السفلي (Range Slider) بألوان ذهبية داكنة.
*   **إزالة المربعات الرمادية:** إخفاء ومسح كلي لجميع الخلفيات الرمادية الحادة الخاصة بـ Tailwind CSS لجعل الموقع يظهر ككتلة تراثية واحدة ومتجانسة.
*   **تفاعلية ذكية:** برمجة ذكية لقوائم الموقع (Tools Menu) بحيث يتم إغلاقها بسلاسة وبشكل يتزامن برمجياً مع المتصفح عند النقر في أي مكان فارغ بالصفحة.

## ⚙️ طريقة التثبيت (Installation)

بما أن الإضافة في مرحلة التطوير وليست على متجر كروم بعد، يمكنك تثبيتها يدوياً كالتالي:

1. قم بتنزيل هذا المستودع كملف مضغوط (ZIP) أو عبر Git:
   ```bash
   git clone https://github.com/monesir/ExForTurath.git
   ```
2. افتح متصفح Google Chrome أو Microsoft Edge.
3. انتقل إلى صفحة الإضافات `chrome://extensions/`.
4. قم بتفعيل خيار **"وضع المطور" (Developer mode)** من الزاوية العلوية اليمنى.
5. اضغط على زر **"تحميل إضافة فُكّ ضغطها" (Load unpacked)**.
6. اختر المجلد `turath-redesign-ext` الذي يحتوي على الملفات.
7. افتح موقع [تراث](https://app.turath.io/) واستمتع بالتجربة الجديدة!

## 🛠️ التقنيات المستخدمة
*   **CSS3:** استخدام المتغيرات (CSS Variables)، الـ Specificity، وأحدث تأثيرات الواجهة الأمامية.
*   **JavaScript:** استخدام `MutationObserver` لالتقاط التغييرات الديناميكية للموقع (Svelte SPA) والتفاعل الذكي مع واجهة المستخدم.
